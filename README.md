# panopto-test: Panopto Embed Test

A minimal test of embedding a Panopto video in a publicly hosted static website.

## Purpose

This repository tests whether a video hosted on DTU Panopto can be embedded and displayed through GitHub Pages.

## Test

The `index.html` page contains the Panopto iframe embed code.

The test checks:

- whether the Panopto video loads correctly;
- whether the video can be played from GitHub Pages;
- whether the video is accessible to users without a DTU login.

## Hosting

The site is intended to be tested using GitHub Pages.

## Notes

The video itself is hosted by Panopto; this repository only contains the HTML embed code.
